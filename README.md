# L'Un des Sens

Responsive French-language restaurant and wine bar website built with plain HTML, CSS, and JavaScript.

## Preview

From this directory, run `python3 -m http.server 8000` and open <http://localhost:8000>.

The menu, prices, opening hours, and restaurant address are sample content to customize. The reservation form is a front-end demonstration only: it validates the fields and displays a confirmation in the browser but does not send a reservation to the restaurant.
